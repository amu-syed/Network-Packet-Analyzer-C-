# Network-Packet-Analyzer-C-

## Overview
This repository contains a C++ cybersecurity application that simulates the interception and analysis of network traffic. It evaluates incoming data packets for insecure protocols and flags potential vulnerabilities, demonstrating core memory management and input validation techniques.

## Features
Traffic Analysis: Evaluates simulated incoming packets and flags insecure network ports (e.g., FTP, Telnet).

# Memory Management:
Utilizes C++ pointers to efficiently process and modify packet data directly in memory.

# Data Structuring:
Implements custom 'structs' to organize network packet attributes such as Source IP, Destination IP, and Target Port.

# Input Validation: 
Features robust stream-clearing loops and error handling to sanitize user input and prevent runtime crashes.
